# Study Case 02: Innovation and Education

📄 Overview
Based on the Figma Design that we did for our app, we split the pages that we coded like this:

Cristina(me) - HomePage ( also linking all the pages together and adding buttons)
Alexandra - Categories/Challenges Page + Singing Page

I used Tailwind CSS in my code for cleaner code and Alexandra sticked to normal CSS, as this is how she felt more comfortable.


🛠️ Technologies Used
- HTML5
- Tailwind CSS ( Cristina )
- Figma (used for layout and visual design references)

✅ Features

- Interactive homepage with hover effects and smooth transitions
- Linked sections for future components
- Singing exercises ( as seen in our Figma Prototype)
- Consistent visual styling using Tailwind

🧭 Project Structure
Here’s the basic flow of the platform so far:

[Homepage]
   └──→ [Categories/ Challenges Page]
                   └──→ [Singing Page]
                              └──→ [Singing with Ted (exercise)]
